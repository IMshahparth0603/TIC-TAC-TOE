# Tic Tac Toe

My very first Java project! 🎉

This Tic Tac Toe game was developed after learning only the basics of Java, and it's a command-line, two-player game.

## Concepts Used

- Basics of Strings
- Basics of Functions
- User input using the `Scanner` class
- `if-else` statements
- Loops
- 1D Arrays

Nothing beyond these concepts was used in this project.

## How to Run

1. Make sure you have JDK 17 or higher installed (this project was developed using JDK 17). You can check your version with:
```bash
   java -version
```
2. Clone this repository.
4. Run it:
```bash
   java ttt
```

## How to Play

- The board has 9 positions, numbered 1 to 9.
- Players take turns entering the position where they want to place their mark (X or O).
- The first player to get three marks in a row (horizontally, vertically, or diagonally) wins.
- If all positions are filled and nobody has won, the game is a draw.
- Further instructions will appear as you proceed through the game.
